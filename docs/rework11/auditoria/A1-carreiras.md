## 1. CAR-11.1 — Como o "estado profissional" é modelado hoje

Não existe um objeto "estado profissional". Há **sete fontes independentes**, e a tela deriva tudo de UMA delas
(`trabalho.atual`) via `modoDoTrabalho`.

| Conceito | Onde mora | Observação |
|---|---|---|
| Rótulo/ocupação de NPC | `Pessoa.ocupacao/ocupacaoId` — `src/motor/tipos.ts:42-45` | Só NPCs; o jogador não usa |
| Vínculo atual (emprego/contrato) | `Trabalho.atual: Emprego` — `tipos.ts:893-894`; `Emprego` `tipos.ts:820-879` (ocupacaoId, empregador, orgId, contrato, salario, clientela, municipioId, postos) | É a ÚNICA fonte de renda de trabalho e a única coisa que a UI lê como "trabalho" |
| Tipo de contrato | `Contrato` `tipos.ts:819` (`clt`,`autonomo`,`informal`,`servidor`,`militar`,`eletivo`...) | Contrato esportivo não é um tipo: atleta é `clt` (ou `autonomo` no tênis) — `dados/ocupacoes.ts:403-406` |
| Empregador / clube | `Emprego.empregador` (string) + `orgId`; para atleta, duplicado em `CarreiraEsportiva.clube/municipioId/nivel` `tipos.ts:1513-1524`; para técnico, `PassagemDeTecnico.clube/municipioId/nivel` `tipos.ts:1663-1673` | Três fontes de "onde trabalha" que podem divergir |

| Modo (o que a UI mostra) | `modoDoTrabalho` `sistemas/profissao.ts:85-124` | `!e` → 'procurando'/'sem_procurar'/... (`:92-102`): ignora `esporte.fase` e `tecnico` |
| Status (desempregado/aposentado) | `desempregadoDesde` `tipos.ts:908`, `aposentadoria` `:904`, `intencao` `:922`, `pausa` `:927` | "Sem clube" vira `desempregadoDesde` (encerrarEmprego `trabalho.ts:536`) |
| Atividade paralela | `Trabalho.paralela` `tipos.ts:933`; pausadas `:938`/`TrajetoriaPausada` `:954-963` | |
| Negócio próprio | `Caminhos.negocio` `tipos.ts:2171`, `Negocio.dedicacao 'integral'|'paralela'` `tipos.ts:2058`; dono integral = `trabalho.atual` com ocupacaoId do negócio (`ambiente.ts:70`) | |
| Militar / política / arte / academia | `Caminhos.militar` `:2173`, `politica` `:2179`, `arte/obras/curriculo/audiovisual` `:2170,2181-2191`, `academia` `:2201` | Cada um com o seu sub-estado |

**Consequência estrutural:** a UI e vários sistemas (oportunidades, ações, mercado, situações, agenda) perguntam
"tem `trabalho.atual`?" e tiram dali tudo. Qualquer estado de carreira que não seja um `Emprego` (atleta sem clube,
técnico sem clube, carreira artística entre trabalhos) fica invisível ou é lido como "desempregado comum".
